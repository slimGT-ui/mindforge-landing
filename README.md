**Твой персональный ИИ-наставник. Учись быстрее, чем когда-либо.**

---

## Особенности

**Персонализация** — Создай свою цель обучения, и ИИ мгновенно её поймет

**Умный план** — Получи пошаговую программу, адаптированную под твой уровень

**Трекинг прогресса** — Красивые дашборды и визуализация твоих достижений

**ИИ-ассистент** — Разбор ошибок и ответы на вопросы в режиме реального времени

## Технологии

- HTML5 — Семантическая разметка
- CSS3 — Современные стили с градиентами и анимациями
- Google Fonts — Шрифт Inter
- Responsive Design — Адаптивный дизайн для всех устройств

## Дизайн

- Мягкие градиенты и фоновые формы
- Плавные анимации
- Карточный дизайн с hover-эффектами
- Цвета: фиолетовый (#8B5CF6) и коралловый (#FF6B57)

## Как запустить

bash
Просто открой index.html в браузере

Или запусти локальный сервер:

python -m http.server 8000
